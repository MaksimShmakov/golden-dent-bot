# Golden Dent Telegram Bot

## Что делает бот

- По `/start` отправляет информационное сообщение с фото `logo-gd.jpg` и 4 кнопками.
- Через 3 дня после первой активации (`/start`) отправляет сообщение с тремя кнопками.
- При "Напомните через 2 недели" ставит повтор через 14 дней.
- При "Не готов записаться" собирает комментарий и пишет в Google Sheets.
- На старте просит ввести ФИО текстом (в формате `Фамилия Имя Отчество`), запрашивает телефон (по кнопке) и сохраняет сегментацию: `tg_username`, ФИО, телефон, `user_id`.
- Поддерживает лист **"БД - клиенты"** с актуальными данными пользователей бота.
- Поддерживает кастомные рассылки через команду `/broadcast` (пошагово: фото, текст, кнопки, база username, подтверждение).
- Администраторы берутся из листа **"Список админов"** Google Sheets.
- Поддерживает админ-редактор контента через `/offers_admin`: можно менять стартовый текст, стартовое фото, заголовок акций, список акций, тексты и кнопки действий прямо в боте.
- Ежедневно в 09:00 по Новосибирску:
  - отправляет напоминания о завтрашних записях,
  - отправляет периодические напоминания по дате последнего визита (блоки 3/6 месяцев).
- В напоминании о записи доступны кнопки: подтверждение, отмена (с выбором причины), перенос записи.
- Статус рассылки/ответа пишется в статус-колонку соответствующего блока:
  - `C` для напоминаний по записи на завтра,
  - `G` для напоминаний 3 месяца,
  - `L` для напоминаний 6 месяцев.
- Если сообщение не доставлено (включая блокировку бота), событие сохраняется в локальную БД и затем выгружается в лист "Не доставлено".

Важно: бот может писать пользователю только после того, как пользователь нажал **Start** у бота.

## Кастомная рассылка

- Запуск: `/broadcast`
- Отмена текущего мастера: `/broadcast_cancel`
- Шаги: фото (или `пропустить`) -> текст -> кнопки (или без кнопок) -> база получателей (`all` или список username) -> подтверждение `отправить`.

## Администраторы

- Бот проверяет доступ админов по листу **"Список админов"**.
- Достаточно заполнить колонку `A` username-ами Telegram: `@username`.
- Можно оставить заголовок в первой строке, например `tg_username`.

## Редактор контента

- Запуск панели: `/offers_admin`
- Отмена шага: `/offers_admin_cancel` или текст `отмена`
- В панели доступны:
- изменение стартового текста
- изменение стартового фото
- изменение заголовка блока акций
- добавление новой акции
- изменение существующей акции
- удаление акции
- предпросмотр стартового экрана и меню акций

## Формат таблицы

Лист **"Записи для бота"**:
- A: `Date` записи на завтра (например `03.02.2026 18:00`)
- B: `tg_username` для записи на завтра (например `@shmaaak`)
- C: `status` для записи на завтра (заполняет бот)
- D: `cancel_reason` для записи на завтра (заполняет бот)
- E: `Date` для напоминания через 3 месяца (опционально)
- F: `tg_username` для напоминания через 3 месяца (опционально)
- G: `status` для напоминания через 3 месяца (заполняет бот)
- J: `Date` для напоминания через 6 месяцев (опционально)
- K: `tg_username` для напоминания через 6 месяцев (опционально)
- L: `status` для напоминания через 6 месяцев (заполняет бот)

Как работает логика:
- Если дата в колонке A равна завтрашнему дню - отправляется сообщение о записи, статус пишется в C.
- Если E/F заполнены, для 3-месячного напоминания используется E/F; иначе бот автоматически берет A/B.
- Если J/K заполнены, для 6-месячного напоминания используется J/K; иначе бот автоматически берет A/B.
- Если выбранная дата для 3 месяцев плюс 3 месяца равна сегодняшней дате - отправляется периодическое напоминание, статус пишется в G.
- Если выбранная дата для 6 месяцев плюс 6 месяцев равна сегодняшней дате - отправляется периодическое напоминание, статус пишется в L.

Лист **"Не готов записаться (комментарии)"**:
- A: дата и время
- B: tg_username
- C: комментарий
- D: ФИО (если есть)
- E: телефон (если есть)

Лист **"Не доставлено"**:
- A: дата и время
- B: tg_username
- C: тип (`appointment`, `3m` или `6m`)
- D: причина

Лист **"БД - клиенты"**:
- A: `tg_username`
- B: `fio`
- C: `phone`
- D: `tg_user_id`

Лист **"Список админов"**:
- A: `tg_username`

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Положите сервисный ключ Google в `service-account.json`.
3. Запустите:

```bash
docker compose up --build
```

Если нужен встроенный `nginx`, запускайте с профилем:

```bash
docker compose --profile webhook up --build
```

## Деплой на чистый Ubuntu сервер

1. Подготовьте сервер:

```bash
sudo apt update
sudo apt install -y ca-certificates curl git
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
sudo systemctl enable docker
```

2. Клонируйте проект:

```bash
sudo mkdir -p /opt/golden-dent
sudo chown -R $USER:$USER /opt/golden-dent
git clone https://github.com/MaksimShmakov/golden-dent-bot.git /opt/golden-dent
cd /opt/golden-dent
```

3. Настройте переменные и сервисный ключ:

```bash
cp .env.example .env
nano .env
nano service-account.json
```

4. Запустите бота (polling):

```bash
docker compose up -d --build
docker compose logs -f api
```

## Вебхук и polling

- Если нет домена/https, используйте polling: `SET_WEBHOOK=false` (режим по умолчанию).
- Если есть публичный https домен, включите вебхук: `SET_WEBHOOK=true` и `WEBHOOK_URL`.
- В `WEBHOOK_SECRET_TOKEN` можно задать секрет для Telegram.
- Вебхук принимает запросы на `/webhook`.
- Для запуска с `nginx` используйте профиль `webhook`:

```bash
docker compose --profile webhook up -d --build
```

## Обновление на сервере

```bash
cd /opt/golden-dent
git pull
docker compose up -d --build
```
